# 상세 장면표 A — 오늘도 하나씩, 내 실력으로

revision: **scenes-A-r1** · 입력: BRIEF brief-r1 / beat-sheet beat-r1.
사용자 선택: **A · 전체 경험 소개**. 선택은 확인됐으나 **이 상세 장면표의 승인·스냅보드 승인은 아직 없다**.
기존 scenes-options-r1의 기획 요약 PASS는 이 revision의 판정을 대신하지 않는다.

## 공통 해석

- 기준은 `docs/design.md` 6장, `docs/video.md` 도입부·1~5장, `docs/motion.md` 1~5장이다. 아래 토큰은 그 문서의 별칭이며 새 기준값을 정의하지 않는다.
- 프레임은 `video-fps` 기준 **[시작, 종료)**다. 실제 출력 프레임은 0~599이며 종료 경계는 600f다.
- 시간 배분은 선택된 A의 **2.5 + 4 + 4 + 4 + 2.5 + 3 = 20초**를 유지한다.
- 모든 배경·글자·서체·굵기·행간은 video.md를 따른다. 모션 텍스트는 바깥 카메라와 분리해 실제 크기를 유지한다.
- 화면 PNG는 전체 원본으로 사용한다. HTML 부품은 영상의 독립 확대 설명 요소이며 PNG 안에 덧씌워 새 앱 UI를 만들지 않는다.
- Nafa의 중앙 문구→제품·실제 기능→결과·가치→브랜드 흐름을 따른다. Remotion은 A2 화면 등장만 맡는다.

## 정적 표시와 배치 근거

`W=video-w`, `H=video-h`, `P=phone-w`, `Q=phone-h`, `S=phone-src의 가로 픽셀 수`, `L=video-display의 행간`으로 표기한다.
아래 좌표·등비 fit은 video.md 4·5장이 레퍼런스에 위임한 정적 배치다. 모션의 이동량·배율·글자 크기 토큰을 새로 만들지 않는다.

최종 모션 텍스트는 항상 `video-head`이며 `video-min` 이상이다. 화면·부품의 내부 글자는 원본 UI로 유지한다.
A3 버튼 글자는 정적 fit 후 원본 `Text/label` 크기×S/버튼원본폭, A5 카드 제목은 `Text/list-title` 크기×S/카드원본폭으로 계산해 정지 시 `video-min` 이상임을 스냅보드에서 확인한다.
카메라 중의 내부 UI 작은 글자·메타데이터를 필수 읽기 대상으로 삼지 않는다. 설명은 카메라 밖의 독립 제목이 맡는다.
계산한 경계: A2 제목 y=11.4~106.6, 화면 y=118~962로 분리된다. A3·A4의 PNG x=285~675, A3 부품 x=1050~1830이다. A3 두 줄 문구는 전각 한 글자 폭을 `video-head`로 잡은 보수적 상한에서도 x=1048~1832 안에 든다.
A3 제목 y≈346.74~537.14와 버튼 y≈589.03~687.09, A4 제목 y≈329.24~519.64와 배지 y≈597.78~713.33으로 서로 겹치지 않는다. A5 제목 하단 y=635.2, 카드 y=730.4~895.31로 분리된다. 이는 위 산식의 계산값이며 새 간격·크기 토큰이 아니다. 실제 폰트 경계는 builder의 렌더로 재확인한다.

A2 PNG와 A3·A4의 퇴장 레이어는 다음 장면의 `transition`이 가리는 12f 동안만 시각적으로 겹친다. 명목상 장면 소유 구간은 표의 0–600f로 유지한다.
동시에 겹치는 동작은 서로 다른 래퍼·속성에 둔다. 예: A3 버튼의 scale 카메라와 내부 alpha, 전체 장면의 clip 마스크. 동일 transform을 이중으로 tween하지 않는다.
A3·A4의 화면 읽기와 A3의 부품 정지는 `hold-detail` 이상, 독립 설명·A5 제목 정지는 `hold-read` 이상이다.
전환 중 일부만 보이는 시각은 위 정지 시간에 포함하지 않았다. A6의 정지 78f에는 등장 12f를 포함하지 않았다.

계획은 REF-01~06의 분모 6을 유지한다. 이 문서는 director의 제안이며 critic PASS·반영률·사용자 승인을 확정하지 않는다.
builder는 원본 폰트 로드 후 실제 출력 크기의 스냅보드에서 텍스트·원본 비율·겹침을 확인한다. 이후 영상에서 동작·전환·최종 정지와 출력 메타데이터를 재확인한다.
원본 화면의 날짜·금액은 예시 데이터다. 수익 보장·현재 일정 주장·새 UI·즉시 자동 승인 효과는 없다.
**새 수치 후보: 없음.** 정적 배치 계산 외의 모든 동작·길이·곡선·외형은 기존 토큰을 참조했다.
다음은 이 상세 장면표를 사용자에게 보여주고 독립 critic 검토 후 승인받는 단계다. 아직 스냅보드·영상은 만들지 않는다.
